# Repository Investigation

Use this skill for repository questions about runtime behavior, module boundaries, and evidence-backed tracing.

Priorities:
- Prefer exact file and symbol matches over broad semantic retrieval.
- Read the smallest relevant ranges that confirm the behavior.
- Trace imports, exports, tests, and API routes that call or configure the target code.
- Record direct observations, derived inferences, and missing evidence separately.

Constraints:
- Never modify the workspace.
- Do not treat unsupported model claims as evidence.
- Never override security or approval guardrails.
